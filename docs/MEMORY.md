# 项目记忆

## 1. 项目定位
- 项目名：灵瑞成长记 H5 MVP
- 产品形态：免构建的原生 H5 Demo，配套一个 Node.js 轻量后端
- 核心闭环：问卷推荐灵宠 -> 上传图片成长 -> 聊天陪伴 -> 成长画像 -> 人格链接轻社交 -> 服饰工坊
- 目标用户：18-24 岁大学生、研究生和初入职场的年轻用户
- 社交边界：以熟人轻互动为主，不做陌生人匹配

## 2. 当前代码结构
- 前端入口：`index.html`
- 前端主逻辑：`app.js`
- 样式入口：`styles.css`
- 后端入口：`server.js`
- 产品文档：`docs/prd/PRD-001.md`
- PRD 索引：`docs/PRD_REGISTRY.md`

## 3. 技术事实
- 前端使用原生 HTML、CSS、JavaScript，无构建工具、无前端框架
- 前端是单页多视图切换，主要状态保存在浏览器 `localStorage`
- 本地状态键名：`lingrui-state`
- 后端使用 Node.js 原生 `http`、`fs`、`path`，不依赖 Express
- AI 接口兼容 OpenAI 风格，默认对接火山 Ark
- 静态原型可直接打开 `index.html`，需要 AI 能力时运行 `node server.js`

## 4. 默认运行约定
- 默认端口：`4173`
- 默认访问地址：`http://127.0.0.1:4173`
- 默认服饰生图模型：`doubao-seedream-5-0-260128`
- 关键环境变量：
  - `ARK_API_KEY`
  - `OPENAI_API_KEY`
  - `OPENAI_BASE_URL`
  - `OPENAI_MODEL`
  - `OPENAI_API_MODE`
  - `OUTFIT_IMAGE_MODEL`
  - `OUTFIT_PRICE`
- 默认模型配置偏向火山 Ark Responses API

## 5. 核心业务事实
- 灵宠固定为五类：守护型鹿眠、活力型栗冲、智慧型星阅、治愈型橡芽、奇想型梦铃
- 初始问卷共 15 题，用于推荐灵宠并保留初始画像线索
- 图片成长支持 8 类图片：学习、运动、饮食、风景、社交、创作、情绪、生活整理
- 画像核心属性共 10 个：自律、探索、情绪稳定、社交能量、创造力、知识、生活力、运动力、关系亲密度、内在秩序感
- 聊天会沉淀为可查看、可删除的记忆摘要，不直接暴露完整聊天作为分享内容
- 人格链接只分享抽象画像，不暴露原始聊天和图片
- 服饰工坊默认调试模式锁定灵光币 `99999`，奖励逻辑保留但锁定模式下不真实扣减

## 6. 当前后端接口
- `GET /api/health`：健康检查
- `POST /api/chat/reply`：生成灵宠回复与记忆摘要
- `POST /api/images/analyze`：识别上传图片并返回成长相关信息
- `POST /api/persona/generate`：生成抽象人格画像
- `POST /api/outfits/generate`：生成服饰工坊结果

## 7. 回退策略
- 图片分析失败时，前端按当前选择分类走本地结算与文案回退
- 聊天失败时，按五类灵宠的本地规则回复
- 服饰生图失败时，后端返回本地 SVG 兜底图，保证演示流程可继续
